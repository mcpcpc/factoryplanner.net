# Factory Planner

Factory Planner is a free, browser-based tool for planning factory layouts. You draw the floor plan, map how materials move between machines, let the planner suggest a layout that cuts travel, and export drawings and CAD files.

**Use it at [app.factoryplanner.net](https://app.factoryplanner.net).**

![Factory Planner Demo](./demo.gif)

## About this repository

The application source code is private. This repository is only for tracking issues with the hosted app at [app.factoryplanner.net](https://app.factoryplanner.net). It holds no application code, and there are no releases or versions to download.

## Reporting issues

To report a bug or request a feature, [open an issue](https://github.com/mcpcpc/factoryplanner.net/issues/new). Search the [existing issues](https://github.com/mcpcpc/factoryplanner.net/issues) first to avoid duplicates.

For a bug, please include:

- What you did, what you expected, and what happened instead
- Your browser and operating system
- Screenshots or an exported layout (JSON), if they help show the problem

Leave out anything you don't want made public, such as client names, addresses or confidential floor plans.

## Reporting security vulnerabilities

**Do not open a public issue for a security vulnerability.** Report it privately through GitHub's [vulnerability reporting](https://github.com/mcpcpc/factoryplanner.net/security/advisories/new) instead. Only the live production app at [app.factoryplanner.net](https://app.factoryplanner.net) is supported. See [SECURITY.md](./SECURITY.md) for details.
