# Security Policy

Thank you for helping keep our web application secure. Because this repository is used exclusively for tracking issues and does not host the application source code or public versioning, please follow the guidelines below to report vulnerabilities.

## Supported Versions

We do not provide public versioning or historical release packages. Security support is restricted exclusively to the live, production instance of the application. 

| Environment | Supported |
| :— | :— |
| Live Production App | ✅ Supported |
| Local, Staging, or Development Builds | ❌ Not Supported |

## Reporting a Vulnerability

**Do not open a public issue.** Publicly disclosing a security bug exposes users to risk before a patch can be deployed.

Please report security issues confidentially through GitHub:

1. Navigate to the **Security** tab at the top of this repository.
2. Select **Vulnerability reporting** from the left-hand menu.
3. Click **Report a vulnerability** to submit your findings privately to the project maintainers.

## Our Commitment

If you report a vulnerability confidentially, we will acknowledge your report, investigate the issue, and notify you once a patch has been deployed to the live production site.
